# Phase 2 Plan 01 — FB visibility (Bug B core)

## Goal

Function-block instances on the live M580 (192.168.112.159) expand to
their public members in the UMAS browser. `M_Elevator` and the 22 other
FB instances stop being bare `(?)` leaves. plc4j functional parity.
New test fixture for FB-member tree assembly. Python stub
`test/umas_stub_server.py` extended with matching fixtures.

## Approach (from 02-RESEARCH.md)

Extend `_expandVariable` in `packages/tfc_dart/lib/core/umas_client.dart`
to speculatively call DD02 with the variable's `dataTypeId` whenever
the type cannot be resolved through the existing
`UmasDataTypes.resolve` path. The DD02 response discriminates on the
first byte: `classId == 0x04` ⇒ array def (existing
`UmasArrayTypeDefinition.tryParse` path); anything else ⇒ UDT/FB
member layout (existing `_parseVariableRecords(isMemberLayout: true)`
parser via `_readDD02Block`). Mirrors plc4j's `resolveCustomType` /
`parseCustomTypeBlock` but extends the gate to also fire when the
variable's type is missing from DD03 — needed because the M580
firmware in question doesn't surface FB types via DD03.

Replace with:

```dart
  /// Recursively expand a variable into its struct/FB members or array elements.
  ///
  /// plc4j(UmasProtocolLogic.java:1079-1097, 1130-1146): for any custom type
  /// reference whose classIdentifier != 0, plc4j issues a DD02 request keyed
  /// on the type's index and inspects the first response byte. classId 0x04
  /// ⇒ UmasArrayTypeDefinition; anything else ⇒ UmasPDUReadUmasUDTDefinitionResponse
  /// (member records). We extend that behaviour to ALSO fire for variables
  /// whose dataTypeId did not appear in DD03 at all — the live M580 at
  /// 192.168.112.159 omits FB types from DD03 even though their UDT bodies
  /// are accessible via DD02-on-typeIndex. plc4j strictly gates on the
  /// non-zero classIdentifier of a *resolved* DD03 record and would silently
  /// drop these FB instances; we resolve speculatively to surface them.
  Future<UmasVariableTreeNode> _expandVariable({
    required UmasVariable variable,
    required String path,
    required List<UmasDataTypeRef> dataTypes,
    required Map<int, List<UmasVariable>> memberCache,
    required Map<int, UmasArrayTypeDefinition?> arrayCache,
    required int depth,
    required int maxDepth,
  }) async {
    UmasDataTypeRef? type = UmasDataTypes.resolve(variable.dataTypeId, dataTypes);
    bool isStructOrFb =
        type != null && (type.classIdentifier == 2 || type.classIdentifier == 7);
    bool isArray = type != null && type.classIdentifier == 4;

    // Speculative FB / UDT resolution for top-level (or recursively-discovered)
    // variables whose type was not enumerated in DD03 and is not a built-in.
    // Mirrors plc4j parseCustomTypeBlock's classId discriminator.
    final isUnresolvedCustom = type == null &&
        depth < maxDepth &&
        !UmasDataTypes.builtIn.containsKey(variable.dataTypeId) &&
        variable.dataTypeId != 0;
    if (isUnresolvedCustom) {
      try {
        // Cache hits short-circuit network I/O. Arrays cached as a non-null
        // UmasArrayTypeDefinition; structs cached as a non-empty member list.
        if (arrayCache.containsKey(variable.dataTypeId) &&
            arrayCache[variable.dataTypeId] != null) {
          isArray = true;
          type = UmasDataTypeRef(
            id: variable.dataTypeId,
            name: type?.name ?? '?',
            byteSize: 0,
            classIdentifier: 4,
            dataType: variable.dataTypeId,
          );
        } else if (memberCache.containsKey(variable.dataTypeId) &&
            memberCache[variable.dataTypeId]!.isNotEmpty) {
          isStructOrFb = true;
          type = UmasDataTypeRef(
            id: variable.dataTypeId,
            name: 'FB',
            byteSize: 0,
            classIdentifier: 7,
            dataType: variable.dataTypeId,
          );
        } else {
          final raw = await readDD02Raw(variable.dataTypeId);
          final asArray = UmasArrayTypeDefinition.tryParse(raw);
          if (asArray != null) {
            arrayCache[variable.dataTypeId] = asArray;
            isArray = true;
            // Synthesize a minimal array-class type so the existing array
            // branch below picks it up. byteSize 0 disables the
            // element-size-from-total fast-path; the array branch then
            // bails to a leaf (acceptable — we have no DD03 byteSize for
            // this type). Real arrays come through DD03 in practice.
            type = UmasDataTypeRef(
              id: variable.dataTypeId,
              name: '?',
              byteSize: 0,
              classIdentifier: 4,
              dataType: asArray.elementTypeId,
            );
          } else {
            // Parse as UmasPDUReadUmasUDTDefinitionResponse — same wire
            // format as the existing `isMemberLayout: true` path. We
            // re-issue via _readDD02Block so the response is parsed
            // through the shared _parseVariableRecords codepath.
            final members = await _readDD02Block(
                blockNo: variable.dataTypeId, isMemberLayout: true);
            if (members.isNotEmpty) {
              memberCache[variable.dataTypeId] = members;
              isStructOrFb = true;
              type = UmasDataTypeRef(
                id: variable.dataTypeId,
                name: 'FB',
                byteSize: 0,
                classIdentifier: 7,
                dataType: variable.dataTypeId,
              );
            } else {
              // Empty/short response (observed on this M580 for type
              // 0xb6 = M_Elevator — single byte 0x00 returned). Cache the
              // miss so other instances of the same type don't re-query.
              memberCache[variable.dataTypeId] = const [];
            }
          }
        }
      } on UmasException catch (e) {
        _log.w('Speculative DD02 resolution failed for type '
            '0x${variable.dataTypeId.toRadixString(16)}: ${e.message}');
        // Cache empty so we don't retry per-instance.
        memberCache[variable.dataTypeId] = const [];
      }
    }

    if (depth >= maxDepth || (!isStructOrFb && !isArray)) {
      return UmasVariableTreeNode(
        name: variable.name,
        path: path,
        children: const [],
        variable: variable,
        dataType: type,
      );
    }
    ...   // rest of method (array branch + struct branch) unchanged
```
